موقع واثق أحمد علي أحمد الدعجري — تعليمات سريعة

الملفات:
- index.html: صفحة الموقع الرئيسية.
- portrait.jpg: ضع صورتك الشخصية بهذا الاسم بجانب index.html (اختياري).

النشر المجاني عبر GitHub Pages من الآيفون:
1. افتح https://github.com في Safari وأنشئ حسابًا أو سجّل الدخول.
2. أنشئ مستودعًا عامًا (Public) باسم مطابق تمامًا لاسم المستخدم متبوعًا بـ .github.io، مثل: yourusername.github.io
3. افتح المستودع ثم Add file > Create new file.
4. سمّ الملف index.html، والصق محتوى ملف index.html من هذه الحزمة، ثم اضغط Commit changes.
5. من المستودع افتح Settings > Pages.
6. في Build and deployment اختر Deploy from a branch، ثم الفرع main والمجلد /(root)، واضغط Save.
7. انتظر بضع دقائق وافتح https://yourusername.github.io

إضافة الصورة:
- يمكن إضافة ملف الصورة من Add file > Upload files، وسمّه portrait.jpg.
- لا ترفع معلومات خاصة أو رقم هاتف شخصي إلا إذا كنت تريد نشرها علنًا.
- الموقع قالب أولي: عدّل النصوص الإرشادية وأضف معلوماتك الحقيقية قبل مشاركة الرابط.
